      Chapter 1 pipeline output recorded runs

      The labels above are the contours we designed. Below are results recorded from real runs of the paper code on three example songs. For each song, the audio rendered by this page was the only input: spectrogram → segments → one genetic-programming search per segment → formulas → tokens → nearest class medoid. This page displays those recorded results; it does not run the genetic program. The runs used GA seed 37, which was not used to build the class medoids. Choose a song to see its run and load it above.

      Live run (local pipeline server)

      The browser sends only the WAV file to the local server; the note labels are not sent. The server runs the paper's code on that audio: spectrogram, segmentation, one genetic-programming search per segment, formula composition, token mapping, and nearest-medoid classification. A run takes about 15–45 seconds per note, depending on the computer.

          Each note is a designed frequency contour rendered as a tone: UP rises, FLAT stays at one frequency, DOWN falls, WIGGLE oscillates. These names describe what we drew, so they are an answer key, not a measurement. The pipeline names a note from the formula the genetic program fits to the spectrogram, so it can disagree with the designed name. See the research pipeline for details.
